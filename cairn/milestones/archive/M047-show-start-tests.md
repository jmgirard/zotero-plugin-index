# M047: Show whether plugins start in Zotero

**Status:** done (2026-10-29, PR #85 https://github.com/jmgirard/zotero-plugin-index/pull/85)

**Goal:** The daily build starts each listed plugin in each tested Zotero release that its manifest covers, and the data and plugin pages show the result.

feature series: M046 -> M047

**Outcome:** `readUpstream` returns `xpi: { url, sha256 }` beside the facts, and `pnpm build --plan <file>` writes a start plan (entry, plugin id, version, manifest bounds, XPI URL and SHA-256) for each record with upstream; `pnpm build` refuses a repeated option. `pnpm start-tests --plan --zotero --out` (`src/start-test/start-tests.ts`) picks items by `inRange` (`compareVersions`), downloads each XPI with the reader's new `downloadXpi`, checks the hash, runs `node src/start-test/cli.ts` per item, records no result for a failed download, a hash mismatch, or a failed start, and starts nothing new after 20 minutes (`summaryLines` prints a `::warning::`). `pnpm add-start-results --data --plan --results --tested` (`src/start-test/add-results.ts`) keeps a result only when its entry, plugin id, version, range, result name, and artifact-name version (listed in `--tested`) all match; it drops duplicate pairs and entries that are not a regular file of at most 1 MiB or cannot be read, and writes `startTests` ordered by version. Schema v1 gains optional `startTests` (`minItems: 1`, requires `upstream`, `zotero` pattern). `build.yml`: a build job (plan; `plugins-data` and `start-plan` artifacts), a start-test matrix for Zotero 7.0.32 (.tar.bz2), 8.0.4, 9.0.6, and 10.0.6 (quoted SHA-256s, `permissions: {}`, `persist-credentials: false`, `cache-mode: none`, 40 min), a site job (`if: ${{ !cancelled() && needs.build.result == 'success' }}`, a `--tested` list that a workflows test matches to the matrix), and deploy (`if:` on the site job's result). The plugin page shows a "Starts in Zotero" line with a note on the 3 s wait. README, CHANGELOG, and DESIGN (a fifth data source, a Known issues entry on forged results).
