# M053: Show the home list as a table

**Status:** done (2026-10-29, PR #102 https://github.com/jmgirard/zotero-plugin-index/pull/102)

**Goal:** The home page lists the plugins in one table, in a new site look that replaces the card look of M048 and M049.

feature series: M053 -> M054

**Outcome:** `site/src/pages/index.astro` is one table sorted by `homeOrder` (display name with `localeCompare` at base sensitivity, then id), with a caption, a `<colgroup>`, and a `th scope="row"` name cell (link, "Archived", shown description). Each row has one cell per `ZOTERO_MAJORS` major with a declared mark (`SUPPORT_MARKS`, hidden `supportText`) and, in its own `span.start`, the `majorStart` result (newest by `compareVersions`, hidden "Start test: …"), or "Not read" for a failure. Further cells hold "Menus and settings" codes from `listedSubtags` (first 2 and "+N" past 3), a `<time>` with `monthYear` in UTC, and source and `.xpi` links that pass `safeHref`, drawn by the new `Icon.astro`. A legend with `role="list"` names each mark and "No mark", and says that a declared range is not a test result. A search box filters with `rowShows(row, language, zotero, query)` (name or description holds the trimmed query, both lowercased) and keeps `?q=`, written 500 ms after typing stops. `filterStatus` now always gives a count. Controls stay hidden in the HTML for no-JS readers. `Base.astro` has new color and size tokens for both schemes, a top bar (home, "Add a plugin", "Data"), and a footer. Control edges take `--faint`. At 760 px or less the language and date columns hide, and at 560 px descriptions and source links. Plugin pages keep the M048 sections. Tests run the minified script in `node:vm` with stand-ins and timers, build in America/New_York so the UTC month can fail, and check 17 token pairs per scheme and the control edges at 3:1. The M049 home-facts snapshot was removed. README, DESIGN, and one CHANGELOG series entry describe it.

**Decisions:** none promoted; `--faint` and `--none` darkened from the mockup to pass 3:1; existing labels "Menus and settings in" and "Declares Zotero" kept.
