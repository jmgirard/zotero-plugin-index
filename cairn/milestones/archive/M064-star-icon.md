# M064: Show the star count with a star icon

**Status:** done (2026-10-30, PR #347 https://github.com/jmgirard/zotero-plugin-index/pull/347)

**Goal:** Each plugin page shows its star count as a gold star icon and a number, not as "N stars".

**Outcome:** The plugin page's repo line (`site/src/pages/plugins/[id]/index.astro`) ends `·`, then `<span data-repo-stars>` with no `title` and two child spans: an `aria-hidden` span whose `title` is `starsText` ("1,234 GitHub Stars", "1 GitHub Star") holding the `star` icon and the count by `toLocaleString("en")`, a space, then a `.visually-hidden` span with the same `starsText`, as M054's declared marks do. `Icon.astro` gains a filled `star` path (Feather's polygon). `Base.astro` adds `--star` (#b07d00 light, 3.39:1 on `--bg`; #e3b341 dark), `[data-repo-stars] .icon` with `fill: var(--star)` and `stroke: none`, `CanvasText` in a later forced-colors block, and `white-space: nowrap` on `[data-repo-stars]`. `test/site.test.ts` holds `--star` at 3:1 on `--bg` and `--surface`, checks the rule order by source, and pins the markup, visible text, `title`, hidden text, and star path for counts 1,234, 1, and 0. README, DESIGN.md, and the M061 CHANGELOG entry (Unreleased) describe the line. The question set chose the darker gold in light mode for 3:1 contrast over GitHub's #e3b341 (1.8:1), and the user asked for the star before the number with a "GitHub Stars" tooltip.
