# References index

This file lists each committed page in `cairn/references/`, one line per
page. A source note (`<citekey>.md`) covers one primary source. A synthesis
note covers an analysis across several sources. This index does not list the
gitignored source shelf (`sources/`).

Write each entry as a bullet line in the form `- page.md: what it covers`.
Do not use table rows. The references check in `cairn_validate` reads only
bullet lines.

- category-ledger.md: a hand read of each plugin's categories on the deployed data of 2026-10-31 (M066)
- mdn-nth-child.md: which browsers read the `of <selector>` form of `:nth-child()` (MDN and its compat data)
- microsoft-naming-a-file.md: which file and directory names Windows refuses (Microsoft's naming rules)
- mozilla-toolkit-version.md: how Zotero and Firefox order version strings (MDN's legacy version format)
- zotero-changelogs.md: the newest release of each Zotero major and the release address's answer (zotero.org)
