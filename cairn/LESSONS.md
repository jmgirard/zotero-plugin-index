# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NNN>): <lesson>`. Limits: at most 25
lessons, each at most 450 bytes. Over the limits, retire, shorten, or split
lessons first. Then the lowest-ranked lesson leaves first. Rank is the newest
milestone in a lesson's provenance, and reviews mark `used M<NNN>` on the
lessons a milestone used. Corrected in place when proven false (never append a
correction).

- 2026-10-25 (M001, used M061): pnpm is not installed on the maintainer's machine, so run it as `npx -y pnpm@12.15.0`. The check, add-plugin, and build tests spawn pnpm through `npm_execpath`, so run them with `pnpm test`, not bare `vitest`. A cold `npx` start once took minutes, which is why the test timeout is 60 s.
- 2026-10-25 (M006, used M059): PyYAML is not installed on the maintainer's machine. To check a workflow's jobs, `if:` keys, and permissions, parse it with `ruby -ryaml -e 'YAML.load_file(".github/workflows/build.yml")'`.
- 2026-10-25 (M007, used M060): Astro inlines a small `<script>` as `type="module"` in the page, so a page test that greps for a selector string also matches the script. Match the attribute form, such as `\sdata-x="`. Since M024 the home page is the one page with a script, the language menu (corrected M015, M024).
- 2026-10-26 (M010, used M061): To plant a defect and undo it, copy the file first and restore from the copy. `git checkout <file>` restores the last commit and drops uncommitted work; once it put a committed stub back over a finished file.
- 2026-10-26 (M014, used M061): `pnpm test -- --reporter=verbose` hands `--` to Vitest, which reads the rest as a file filter and prints no test names. For per-test names, run `npx -y pnpm@12.15.0 exec vitest run --reporter=verbose` after `pnpm test`. `pnpm exec` still sets `npm_execpath`, so the spawn tests run.
- 2026-10-26 (M015, used M061): The built-in browser pane cannot screenshot or read a `file://` page. To view a built site, add a `.claude/launch.json` entry running `python3 -m http.server <port> --directory <dir>` with the site at `<dir>/zotero-plugin-index/` so Pages-path links resolve, keep the file out of git through `.git/info/exclude`, then `preview_start` it. The pane's light-scheme emulation did not apply.
- 2026-10-26 (M018, used M058, corrected M020): README, CHANGELOG, and DESIGN wrap prose near 76 columns, so `grep` for a phrase misses one split across lines. Search a joined copy: `tr '\n' ' ' < README.md | sed 's/  */ /g' | grep -o '<phrase>' | wc -l`. The joined copy is one line, so `grep -c` prints at most 1. Also strip `//` or `#` comment marks for code comments.
- 2026-10-27 (M021, used M061): An Astro template drops the line break between text and an element on the next line, so "Report that it" then `<a>Works</a>` rendered as "itWorks". Write `{" "}` at the line end. Read the built page's text, not only the template, since the site tests match markup. A test that strips tags must add no space for them, or it hides the dropped one.
- 2026-10-27 (M024, used M058): Astro writes an attribute whose value is `""` as its bare name, because its `addAttribute` tests `value === ""`, so a test that matches `\sdata-x="` misses it. Pass `new String("")`, which Astro writes as `data-x=""`, as `rowLanguagesAttribute` in `site/src/data.ts` does.
- 2026-10-27 (M027, used M061): `npx -y pnpm@12.15.0 exec vitest` once hung 7 minutes inside npm before Vitest started. A test file that spawns no pnpm, such as `test/upstream.test.ts`, also runs as `./node_modules/.bin/vitest run <file>`, which starts in seconds; the spawn tests still need `pnpm test`.
- 2026-10-28 (M035, used M061): A local `dist/v1/plugins.json` can predate newer data fields, so a site built from it showed a language menu with no options. For a hand check of the real site, download the deployed `https://jmgirard.github.io/zotero-plugin-index/v1/plugins.json` into `<dir>/v1/`, then run `pnpm site --out <dir>`.
- 2026-10-27 (M030, used M056): Vitest's fake timers do not replace the timer behind `execFile`'s `timeout`, so test a git limit with a short real limit and a `PATH` shim that runs `exec sleep 600`. For a `performance.now()` limit, `vi.spyOn(performance, "now")` and move its value from `fixtureFetch`'s `onRequest` on the stalled URL, so the cut needs no real wait.
- 2026-10-28 (M036, used M061): An Edit whose old text ends before a line's end leaves the rest of that line joined to the last new line, so rewrapping README or CHANGELOG prose left lines of 94 to 129 characters. End the old text at a line break, then list long added lines: `git diff -U0 main | grep '^+' | awk 'length > 80'`.
- 2026-10-28 (M037, used M058): Astro writes a template's markup as given, so a `<div>` inside a `<p>` passes a regex test of the built HTML, but the browser's parser closes the `<p>` at the `<div>`, which moves the content out of a `hidden` `<p>` wrapper. Wrap block content in a `<div>`, and check nesting in the browser pane with `new DOMParser().parseFromString(html, "text/html")` on the fetched page.
- 2026-10-28 (M043, used M059): To check that GitHub accepts a changed workflow file, push the branch and run `gh workflow run <file> --ref <branch>`: a workflow whose jobs all skip off the default branch runs none and concludes `skipped`, and `gh run view` shows any file error. Such a dispatch still joins the file's concurrency group, so first make sure that `gh run list` shows no run of it waiting.
- 2026-10-29 (M047, used M059): YAML reads an unquoted all-digit value as a number, so a planted SHA-256 of zeros reached a workflow's `sha256sum --check` as `0` and failed as "no properly formatted checksum lines found", not as a mismatch: quote each hash. GitHub skips a job whose earlier jobs include a failed one, even two `needs` away, unless its `if:` names the result it needs, such as `${{ !cancelled() && needs.site.result == 'success' }}`.
- 2026-10-29 (M048, used M053): Astro inlines a page's CSS only while it stays under 4 KB (`build.inlineStylesheets: "auto"`). Past that each page links `_astro/Base.<hash>.css`, and no markup test notices. `site/astro.config.ts` sets `inlineStylesheets: "always"`, and a site test checks each page for a `<style>` and no stylesheet link.
- 2026-10-29 (M048, used M060): To check page width at several sizes in the browser pane without resizing it, load each page in a same-origin `<iframe>` of that width from one `javascript_tool` call and compare `contentDocument.documentElement.scrollWidth` with `clientWidth`. Append a 900 px `<div>` once to see the check fail.
- 2026-10-29 (M053, used M060): The built home page minifies its script and CSS: names are mangled, and `max-width: 760px` becomes `width<=760px`, so a test cannot grep for `rowShows` or match a style with `[^<]*`. To test the script, run the built text in `node:vm` with stand-in elements and timers, as `homeScript` in `test/site.test.ts` does; its stand-ins throw on a selector they do not know.
- 2026-10-29 (M054, used M058): The layout sets `overflow-wrap: anywhere` on `body`, so a narrow table header broke mid-word ("Zo ter o") at 375 px while the iframe width check still passed. Set `overflow-wrap: normal` on a table so its words break only at spaces, and look at the 375 px view in the browser pane, since the width check cannot see a broken word.
- 2026-10-30 (M057, used M059): A workflow run started by hand checks out the commit its branch held at dispatch, even while it waits queued in a concurrency group. A `Discover plugins` run dispatched while a merge run went on read the old `plugins/` and drafted 54 entries the merge then landed; its write step skipped them, but they spent the read budget. Start each backfill step only after the previous run completes.
- 2026-10-30 (M059): fflate's `zipSync` writes a zip's time from local date parts, so `mtime: "2026-01-01T00:00:00Z"` gave different bytes, and a different SHA-256, under UTC and New York time. A time built from local parts, `new Date(2026, 0, 1)`, gives the same bytes in every zone; `test/support/fixture-fetch.ts` zips fixture XPIs that way, so a golden data file can hold their SHA-256.
- 2026-10-30 (M060): An Astro page can carry a tested function in a classic `<script is:inline set:html={text}>` whose frontmatter text holds `${fn}`: the site build strips its types and comments and does not minify it, so the function must call and read nothing outside its body except built-ins, as `prePaintStyle` in `src/site/home-filter.ts` does. A site test runs the built classic script in `node:vm`.
- 2026-10-30 (M060): The browser pane records no `paint` entries, so first paint cannot be timed there. To see what a page shows before its module script runs, serve a copy of the built page with that script cut out and compare which rows have `display` other than `none` in same-origin iframes; an iframe with `sandbox="allow-same-origin"` shows the page with scripts off. A later window listener can undo the state such a copy measures.
- 2026-10-30 (M061): `upstream.repoUrl` is always GitHub's `html_url`, so a site-fixture case for an odd repo URL (a query, a GitLab host, `http:`) belongs on a failure record, whose `repoUrl` comes from a hand-typed `meta.json`; on an upstream record it builds pages GitHub never yields, such as a `…#readme/releases` link. `test/site.test.ts` lists every fixture id in home order by hand in three tests, so a new record goes into each.
