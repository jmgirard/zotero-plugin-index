# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NNN>): <lesson>`. Limits: at most 25
lessons, each at most 450 bytes. Over the limits, retire, shorten, or split
lessons first. Then the lowest-ranked lesson leaves first. Rank is the newest
milestone in a lesson's provenance, and reviews mark `used M<NNN>` on the
lessons a milestone used. Corrected in place when proven false (never append a
correction).

- 2026-10-25 (M001, used M035): pnpm is not installed on the maintainer's machine, so run it as `npx -y pnpm@12.15.0`. The check, add-plugin, and build tests spawn pnpm through `npm_execpath`, so run them with `pnpm test`, not bare `vitest`. A cold `npx` start once took minutes, which is why the test timeout is 60 s.
- 2026-10-25 (M002, used M027): To run a CLI against recorded responses, start pnpm with `NODE_OPTIONS=--import=<abs path>/test/support/preload-fixture.ts` and `ZPI_FIXTURE=<fixture>`; the preload replaces `globalThis.fetch`. Keep a failing-fixture test beside the passing one, since a passing CLI test also passes against the live network.
- 2026-10-25 (M002, used M023): Plugin-template repos keep `update.json` in a prerelease tagged `release` with no `.xpi`, and some manifests use `__MSG_name__` with `_locales/<default_locale>/messages.json`. Read real XPIs before assuming manifest shape.
- 2026-10-25 (M003, used M029): The reader turns every fetch rejection into `request-failed`, so a test of an error the reader does not name makes fetch resolve to an object that throws on read. `await` reads `then` on a resolved value, so a Proxy that throws on every property rejects at once; return `undefined` for `then`.
- 2026-10-25 (M004, used M029): The reader's host check does DNS. Reader tests pass `{ lookup }` to `readUpstream`, a test that calls `buildData` in-process spies on `dns.promises.lookup`, and spawned CLIs get a stub from the preload. Without a stub, a test needs the network.
- 2026-10-25 (M006, used M029): The `github-pages` environment takes deploys from `main` only. A `build.yml` dispatch on a branch checks the build job and its Pages artifact, then the deploy job fails with "not allowed to deploy to github-pages due to environment protection rules". Check the live URLs only after the merge.
- 2026-10-25 (M006, used M029): PyYAML is not installed on the maintainer's machine. To check a workflow's jobs, `if:` keys, and permissions, parse it with `ruby -ryaml -e 'YAML.load_file(".github/workflows/build.yml")'`.
- 2026-10-25 (M007, used M024): Astro inlines a small `<script>` as `type="module"` in the page, so a page test that greps for a selector string also matches the script. Match the attribute form, such as `\sdata-x="`. Since M024 the home page is the one page with a script, the language menu (corrected M015, M024).
- 2026-10-26 (M010, used M035): To plant a defect and undo it, copy the file first and restore from the copy. `git checkout <file>` restores the last commit and drops uncommitted work; once it put a committed stub back over a finished file.
- 2026-10-26 (M012, used M027): fflate's `unzipSync` with a declared size throws "offset is out of bounds" on a stored deflate block that starts past that size, so a zip-bomb fixture made of repeated `Z_SYNC_FLUSH` blocks fails at once instead of holding the old reader. Build such a fixture as one `deflateRawSync` stream: 512 MiB of zeros at level 9 gives 521,826 bytes in about 1.25 s.
- 2026-10-26 (M014, used M033): `pnpm test -- --reporter=verbose` hands `--` to Vitest, which reads the rest as a file filter and prints no test names. For per-test names, run `npx -y pnpm@12.15.0 exec vitest run --reporter=verbose` after `pnpm test`. `pnpm exec` still sets `npm_execpath`, so the spawn tests run.
- 2026-10-26 (M015, used M035): The built-in browser pane cannot screenshot or read a `file://` page. To view a built site, add a `.claude/launch.json` entry running `python3 -m http.server <port> --directory <dir>` with the site at `<dir>/zotero-plugin-index/` so Pages-path links resolve, keep the file out of git through `.git/info/exclude`, then `preview_start` it. The pane's light-scheme emulation did not apply.
- 2026-10-26 (M018, used M035, corrected M020): README, CHANGELOG, and DESIGN wrap prose near 76 columns, so `grep` for a phrase misses one split across lines. Search a joined copy: `tr '\n' ' ' < README.md | sed 's/  */ /g' | grep -o '<phrase>' | wc -l`. The joined copy is one line, so `grep -c` prints at most 1. Also strip `//` or `#` comment marks for code comments.
- 2026-10-27 (M021, used M033): An Astro template drops the line break between text and an element on the next line, so "Report that it" then `<a>Works</a>` rendered as "itWorks". Write `{" "}` at the line end. Read the built page's text, not only the template, since the site tests match markup.
- 2026-10-27 (M024): Astro writes an attribute whose value is `""` as its bare name, because its `addAttribute` tests `value === ""`, so a test that matches `\sdata-x="` misses it. Pass `new String("")`, which Astro writes as `data-x=""`, as `rowLanguagesAttribute` in `site/src/data.ts` does.
- 2026-10-27 (M022, used M030): To make a spawned command such as git fail inside an in-process test, set `process.env.PATH` to an empty temp dir around the call and restore it in `finally`; `execFile` then fails with ENOENT. Build any git checkout the test needs before you clear PATH.
- 2026-10-27 (M027, used M034): fflate's `Inflate.push` decodes its whole input chunk before it calls `ondata`, so a size check in the callback stops a deflate bomb only after one chunk's output, up to 1032 times its size. Many zip headers can point at one bomb, so a budget of declared sizes is no bound: push small chunks (1 KiB gives at most about 1 MiB) and charge the real output.
- 2026-10-27 (M027, used M035): `npx -y pnpm@12.15.0 exec vitest` once hung 7 minutes inside npm before Vitest started. A test file that spawns no pnpm, such as `test/upstream.test.ts`, also runs as `./node_modules/.bin/vitest run <file>`, which starts in seconds; the spawn tests still need `pnpm test`.
- 2026-10-27 (M025): `Intl.DisplayNames` with `fallback: "none"` gives no name for a whole tag whose region it does not know, such as `en-XX`, so name the language subtag, `new Intl.Locale(tag).language`. It names `zxx` and `mul`; `qaa` (private use) and `mis` get none, so `qaa` is a probe no later language data can name.
- 2026-10-27 (M029, used M030): A Vitest fake-timer test that advances the clock a fixed number of times passed locally and timed out on the CI runner, where the real I/O before the timer is set takes longer. Advance the clock once the code reaches the wait instead, for example from `fixtureFetch`'s `onRequest` hook on the stalled URL.
- 2026-10-27 (M030): A `pnpm` or `sh` child that starts its own child keeps the output pipe open after `child.kill()`, so `spawn`'s `close` never fires. To stop such a child at a time limit, spawn it with `detached: true`, kill the group with `process.kill(-child.pid, "SIGKILL")`, and settle at once. `execFile`'s `timeout` does call back, since Node destroys the pipes first.
- 2026-10-28 (M031): A macOS volume ignores case by default, so the `test/check.test.ts` case for names that differ only by case skips there. To run it, make a case-sensitive volume: `hdiutil create -size 50m -fs "Case-sensitive APFS" -volname zpicase <dmg>`, then `hdiutil attach -nobrowse <dmg>`, run Vitest with `TMPDIR=/Volumes/zpicase/tmp`, and `hdiutil detach` the volume after. The Linux CI runner runs the case every time.
- 2026-10-28 (M032, used M034): The Edit and Write tools write a `\u` escape followed by hex digits in new text as the raw character, so a test meant to hold the escape for U+200B gets an invisible U+200B; `\n` and `\s` stay as written. Write such escapes with a short Python replace, then count raw U+200B, U+200D, and U+FEFF in each file, tracking lines that quote an escape included.
- 2026-10-28 (M035): A local `dist/v1/plugins.json` can predate newer data fields, so a site built from it showed a language menu with no options. For a hand check of the real site, download the deployed `https://jmgirard.github.io/zotero-plugin-index/v1/plugins.json` into `<dir>/v1/`, then run `pnpm site --out <dir>`.
- 2026-10-27 (M030): Vitest's fake timers do not replace the timer behind `execFile`'s `timeout`, so test a git limit with a short real limit and a `PATH` shim that runs `exec sleep 600`. For a `performance.now()` limit, `vi.spyOn(performance, "now")` and move its value from `fixtureFetch`'s `onRequest` on the stalled URL, so the cut needs no real wait.
