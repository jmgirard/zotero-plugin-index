# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NNN>): <lesson>`. Limits: at most 25
lessons, each at most 450 bytes. Over the limits, retire, shorten, or split
lessons first. Then the lowest-ranked lesson leaves first. Rank is the newest
milestone in a lesson's provenance, and reviews mark `used M<NNN>` on the
lessons a milestone used. Corrected in place when proven false (never append a
correction).

- 2026-10-25 (M001, used M049): pnpm is not installed on the maintainer's machine, so run it as `npx -y pnpm@12.15.0`. The check, add-plugin, and build tests spawn pnpm through `npm_execpath`, so run them with `pnpm test`, not bare `vitest`. A cold `npx` start once took minutes, which is why the test timeout is 60 s.
- 2026-10-25 (M006, used M047, corrected M047): The `github-pages` environment takes deploys from `main` only. A `build.yml` dispatch on a branch runs the jobs before deploy and the Pages artifact, then the deploy job fails with "not allowed to deploy to github-pages due to environment protection rules". Check the live URLs only after the merge.
- 2026-10-25 (M006, used M047): PyYAML is not installed on the maintainer's machine. To check a workflow's jobs, `if:` keys, and permissions, parse it with `ruby -ryaml -e 'YAML.load_file(".github/workflows/build.yml")'`.
- 2026-10-25 (M007, used M049): Astro inlines a small `<script>` as `type="module"` in the page, so a page test that greps for a selector string also matches the script. Match the attribute form, such as `\sdata-x="`. Since M024 the home page is the one page with a script, the language menu (corrected M015, M024).
- 2026-10-26 (M010, used M049): To plant a defect and undo it, copy the file first and restore from the copy. `git checkout <file>` restores the last commit and drops uncommitted work; once it put a committed stub back over a finished file.
- 2026-10-26 (M014, used M049): `pnpm test -- --reporter=verbose` hands `--` to Vitest, which reads the rest as a file filter and prints no test names. For per-test names, run `npx -y pnpm@12.15.0 exec vitest run --reporter=verbose` after `pnpm test`. `pnpm exec` still sets `npm_execpath`, so the spawn tests run.
- 2026-10-26 (M015, used M049): The built-in browser pane cannot screenshot or read a `file://` page. To view a built site, add a `.claude/launch.json` entry running `python3 -m http.server <port> --directory <dir>` with the site at `<dir>/zotero-plugin-index/` so Pages-path links resolve, keep the file out of git through `.git/info/exclude`, then `preview_start` it. The pane's light-scheme emulation did not apply.
- 2026-10-26 (M018, used M045, corrected M020): README, CHANGELOG, and DESIGN wrap prose near 76 columns, so `grep` for a phrase misses one split across lines. Search a joined copy: `tr '\n' ' ' < README.md | sed 's/  */ /g' | grep -o '<phrase>' | wc -l`. The joined copy is one line, so `grep -c` prints at most 1. Also strip `//` or `#` comment marks for code comments.
- 2026-10-27 (M021, used M048): An Astro template drops the line break between text and an element on the next line, so "Report that it" then `<a>Works</a>` rendered as "itWorks". Write `{" "}` at the line end. Read the built page's text, not only the template, since the site tests match markup.
- 2026-10-27 (M024, used M049): Astro writes an attribute whose value is `""` as its bare name, because its `addAttribute` tests `value === ""`, so a test that matches `\sdata-x="` misses it. Pass `new String("")`, which Astro writes as `data-x=""`, as `rowLanguagesAttribute` in `site/src/data.ts` does.
- 2026-10-27 (M022, used M042): To make a spawned command such as git fail inside an in-process test, set `process.env.PATH` to an empty temp dir around the call and restore it in `finally`; `execFile` then fails with ENOENT. Build any git checkout the test needs before you clear PATH.
- 2026-10-27 (M027, used M046): fflate's `Inflate.push` decodes its whole input chunk before it calls `ondata`, so a size check in the callback stops a deflate bomb only after one chunk's output, up to 1032 times its size. Many zip headers can point at one bomb, so a budget of declared sizes is no bound: push small chunks (1 KiB gives at most about 1 MiB) and charge the real output.
- 2026-10-27 (M027, used M047): `npx -y pnpm@12.15.0 exec vitest` once hung 7 minutes inside npm before Vitest started. A test file that spawns no pnpm, such as `test/upstream.test.ts`, also runs as `./node_modules/.bin/vitest run <file>`, which starts in seconds; the spawn tests still need `pnpm test`.
- 2026-10-27 (M030, used M046): A `pnpm` or `sh` child that starts its own child keeps the output pipe open after `child.kill()`, so `spawn`'s `close` never fires. To stop such a child at a time limit, spawn it with `detached: true`, kill the group with `process.kill(-child.pid, "SIGKILL")`, and settle at once. `execFile`'s `timeout` does call back, since Node destroys the pipes first.
- 2026-10-28 (M035, used M048): A local `dist/v1/plugins.json` can predate newer data fields, so a site built from it showed a language menu with no options. For a hand check of the real site, download the deployed `https://jmgirard.github.io/zotero-plugin-index/v1/plugins.json` into `<dir>/v1/`, then run `pnpm site --out <dir>`.
- 2026-10-27 (M030, used M047): Vitest's fake timers do not replace the timer behind `execFile`'s `timeout`, so test a git limit with a short real limit and a `PATH` shim that runs `exec sleep 600`. For a `performance.now()` limit, `vi.spyOn(performance, "now")` and move its value from `fixtureFetch`'s `onRequest` on the stalled URL, so the cut needs no real wait.
- 2026-10-28 (M036, used M049): An Edit whose old text ends before a line's end leaves the rest of that line joined to the last new line, so rewrapping README or CHANGELOG prose left lines of 94 to 129 characters. End the old text at a line break, then list long added lines: `git diff -U0 main | grep '^+' | awk 'length > 80'`.
- 2026-10-28 (M037, used M048): Astro writes a template's markup as given, so a `<div>` inside a `<p>` passes a regex test of the built HTML, but the browser's parser closes the `<p>` at the `<div>`, which moves the content out of a `hidden` `<p>` wrapper. Wrap block content in a `<div>`, and check nesting in the browser pane with `new DOMParser().parseFromString(html, "text/html")` on the fetched page.
- 2026-10-28 (M038, used M048): Full `pnpm test` runs failed time-limit tests (the 1000 ms pnpm check case in `test/propose.test.ts`, a cached-copy case in `test/registry-schema.test.ts`) under a load average near 7; alone they passed. Read `uptime`. For a baseline, run `git worktree add --detach <dir> main`, symlink `node_modules` into it, and run `pnpm test` there. Give a shim test a short limit only when its shim never ends.
- 2026-10-28 (M042, used M047): `promisify(execFile)` keeps at most 1 MiB of output by default. Past that, Node kills git and sets `killed`, as a timeout does, so check `code === "ERR_CHILD_PROCESS_STDIO_MAXBUFFER"` first, as `gitRunner` in `src/discover/propose.ts` does. To feed stdin, as `git cat-file --batch` needs, call `run(...).child.stdin.end(input)`, and read with `encoding: "buffer"`, since its sizes count bytes.
- 2026-10-28 (M043, used M047): To check that GitHub accepts a changed workflow file, push the branch and run `gh workflow run <file> --ref <branch>`: a workflow whose jobs all skip off the default branch runs none and concludes `skipped`, and `gh run view` shows any file error. Such a dispatch still joins the file's concurrency group, so first make sure that `gh run list` shows no run of it waiting.
- 2026-10-28 (M046, used M047): Zotero runs headless with `MOZ_HEADLESS=1 <zotero> -no-remote -profile <dir>` (Linux also under `xvfb-run`). A plugin loaded from `<profile>/extensions` at start can throw before another plugin listens, and Zotero clears early console text, so install it after `Zotero.uiReadyPromise` with `AddonManager.getInstallForFile` and watch for "Error running bootstrap method 'startup' on <id>"; async rejections log it too.
- 2026-10-29 (M047): YAML reads an unquoted all-digit value as a number, so a planted SHA-256 of zeros reached a workflow's `sha256sum --check` as `0` and failed as "no properly formatted checksum lines found", not as a mismatch: quote each hash. GitHub skips a job whose earlier jobs include a failed one, even two `needs` away, unless its `if:` names the result it needs, such as `${{ !cancelled() && needs.site.result == 'success' }}`.
- 2026-10-29 (M048): Astro inlines a page's CSS only while it stays under 4 KB (`build.inlineStylesheets: "auto"`). Past that each page links `_astro/Base.<hash>.css`, and no markup test notices. `site/astro.config.ts` sets `inlineStylesheets: "always"`, and a site test checks each page for a `<style>` and no stylesheet link.
- 2026-10-29 (M048, used M049): To check page width at several sizes in the browser pane without resizing it, load each page in a same-origin `<iframe>` of that width from one `javascript_tool` call and compare `contentDocument.documentElement.scrollWidth` with `clientWidth`. Append a 900 px `<div>` once to see the check fail.
